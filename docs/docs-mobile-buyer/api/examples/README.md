# Synthetic contract examples

These JSON documents are **source-derived synthetic examples**, never live captures. UUIDs, contact fields, emails under example.invalid, text, secrets and URLs are invented. They are parser/repository fixture inputs, not test accounts or usable credentials. Binary placeholders must never be sent as real uploads.

Read [operation contracts](../operations.md) and [wire definitions](../field-index.md) for validation and nullability; examples do not exhaust enum values or assert a backend exchange passed. Fixed timestamps must be adapted using a controlled test clock for age/expiry tests.
