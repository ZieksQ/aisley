# Project Instructions

## Project
This is a general B2B2C e-commerce application.

The system has four primary users:

- Customer (buyer) - browse products, manages cart, and place orders.
- Seller - add new products, manages orders, manages store.
- Admin - manages application, approve sellers, analytics.
- Courier (riders) - track order, deliver order.

## Stack
- Laravel API
- React + TypeScript
- PostgreSQL (Supabase)

## Rules
- Don't add dependencies without justification.
- Read `@docs` folder for project context.


## Development
- Run test after modifying backend code.
- Don't modify unrelated files.
- Explain significant architectural decisions.
- Create new git branch for each feature you are working on.
- Commit changes in git when accepted
